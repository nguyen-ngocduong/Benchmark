### 1.1 Survey CLM-v0.1-8B (1 tiếng)

**Từ HuggingFace:** https://huggingface.co/Contrastive-LM/CLM-v0.1-8B

**Thông tin đã biết:**
```yaml
Architecture:
  - Base: Frozen Qwen3-8B (last-token-pooled embeddings)
  - Projection heads: state head + action head
  - Loss: Bidirectional InfoNCE
  - Parameters: 8B total

Benchmark vs JEV:
  - Zero-shot (computer-use, gaming, tool-calling): On par with Jev
  - Latency: 9× lower than Jev

Training:
  - Pre-training: ~60M Nemotron Q&A pairs
  - Mid-training: ~30M synthetic hard negatives
  - Post-training: ~1M agentic trajectories
```

### 3.1 Viết Inference Runner (1.5 tiếng)

**File:** `inference_runner.py`

```python
class ModelRunner:
    """Base class cho model runners"""

class CLMRunner(ModelRunner):
    """Run CLM model via clm-serve API"""

    def __init__(self, api_url: str = "http://localhost:8000"):
        self.client = CLMClient()

    def format_for_clm(self, messages: list, tools: list) -> dict:
        """Convert messages + tools sang CLM format:
        state: conversation history
        questions: available tools as Choice definitions
        """

    def extract_tool_calls(self, response: CLMResponse) -> list:
        """Extract predicted tool calls từ CLM response"""

    def run(self, messages: list, tools: list) -> dict:
        """Main inference"""

class JEVRunner(ModelRunner):
    """Run JEV model - implement sau khi research xong"""

    def run(self, messages: list, tools: list) -> dict:
        """Main inference"""
```
